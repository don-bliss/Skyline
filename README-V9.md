# SkyLine v9

This package is the reviewed UI update based on SkyLine v8.

## Included fixes
- Functional Dark mode switch is placed directly below Features in the side drawer.
- Theme choice persists across refreshes using the existing SkyLine theme preference.
- Drawer profile header is clickable and opens the signed-in user's profile page.
- Current-user profile cards/icons across the app route to `profile.html`.
- Existing four-button bottom navigation remains unchanged.
- Existing Trends / Mutuals / Explore / Marketplace and wallet/API scaffolding are retained.

## Publishing
Replace the contents of the new GitHub Pages repository with the contents of this package. Do not merge individual files into the previous repository; this package is intended to be the clean replacement base.
